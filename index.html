Weighted personal scoring

Scores weigh more than nine venue categories, so a great bakery and a great bar are judged on their own terms.

Search that keeps up

Debounced search understands locations, so results update as you type without hammering the network.

Venue data from multiple providers is normalized into a single shape, with consistent category mapping.

Geospatial caching avoids repeat lookups for places you’ve already seen nearby.
